# BraidArt Bug Reports / Signalement de bogues BraidArt

[English](#english) · [Français](#français)

## English

Use this repository to report bugs in BraidArt. [Open an issue](https://github.com/christophe0606/BraidArtBugs/issues/new) and include the BraidArt version, your device and OS version, the steps to reproduce the issue, what happened, and what you expected to happen.

BraidArt is a personal project. I have limited time to review reports, so I may be unable to respond to or fix every issue.

Please remove personal information from your report and any attached screenshots.

## Français

Ce dépôt sert à signaler les bogues de BraidArt. [Ouvrez un ticket](https://github.com/christophe0606/BraidArtBugs/issues/new) et indiquez la version de BraidArt, le modèle de votre appareil, la version du système, les étapes pour reproduire le problème, le résultat obtenu et le résultat attendu.

BraidArt est un projet personnel. Le temps que je peux consacrer aux signalements est limité. Il se peut que je ne puisse pas répondre à tous les signalements ni corriger tous les bogues.

Merci de retirer toute information personnelle de votre signalement et des captures d’écran jointes.
